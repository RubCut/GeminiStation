# Мемный звук: грустный тромбон

Установите `examples/meme-sound-plugin.zip` в веб-панели Gemini Station и подтвердите на станции. После установки попросите: «Гемини, проиграй мемный звук» или «сыграй звук провала».

Архив содержит только `plugin.json` и `plugin.py`, не запрашивает `adb_shell` и не использует сеть. Звук синтезируется из простых волн на месте, а не скачивается или копируется из чужих записей. Он воспроизводится через медиавыход Android на текущей громкости. Плагину нужен установленный Python Plugin Runner; сам Runner имеет доступ к сети, как и остальные плагины. Громкость устройства и текущий маршрут аудио влияют на слышимость. На конкретной станции воспроизведение нужно проверить отдельно.

Пересоздать архив после изменения исходников: `python3 tools/build_meme_plugin.py` из корня репозитория.
