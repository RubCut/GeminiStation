Фоновый звук

Приглушение других приложений во время диалога.

Приглушать фоновый звукАссистент попросит Android приглушить другие приложения, не меняя системную громкость.

Android определяет уровень приглушения: он может быть значительно сильнее 15%, а некоторые приложения могут остановиться. После ответа фоновый звук должен вернуться; зависит от прошивки и приложения.

DNS для Gemini

Используется для Gemini Live, ответов, TTS и поиска YouTube.

Использовать свой DNSЕсли выключено, используется системный DNS станции.

По умолчанию WebShift. IP использует обычный незашифрованный DNS; HTTPS — DNS-over-HTTPS. Настройка не меняет DNS других приложений.

Автоматически отключать свой DNS при VPNПока VPN используется этим приложением, брать DNS системы/VPN; после отключения VPN свой DNS вернётся.

Точная настройка распознавания

Баланс скорости, чувствительности и защиты от ложных срабатываний.

Ожидание слова происходит локально. После срабатывания распознавание команды выполняется в Gemini Live. Эти значения применяются со следующего запуска распознавания.

100–600. Меньше — легче разбудить, но больше ложных срабатываний. Работает при включённом дополнительном фильтре.

200–900. Увеличьте, если слово часто пропускается после паузы.

700–3000. Более длинное окно допускает паузы, но может увеличивать ложные активации.

2000–15000 после готовности микрофона.

400–3000. Меньше — быстрее ответ, выше риск обрезать фразу.

800–5000, если итог от Gemini ещё не пришёл.

Подключаться параллельно со звуковым сигналомУскоряет старт. Микрофон и передача аудио начнутся только после завершения сигнала.
Слушать, пока Gemini подключаетсяПосле сигнала можно говорить сразу. До подключения звук хранится только в памяти (до 10 секунд), затем отправляется в Gemini. Если подключение не удалось, буфер удаляется.

Умный дом

Пока доступны включение и выключение отдельных устройств.

ЭКСПЕРИМЕНТАЛЬНО

При подключении названия устройств и комнат передаются Gemini для выбора команды. Сначала проверьте существующий QR-вход: проверка только читает устройства и не управляет ими. Если Яндекс откажет, нужен отдельный OAuth-токен с правами iot:view и iot:control.

Подключить отдельный OAuth-токен

Если чтение работает, но Яндекс возвращает HTTP 403 при управлении, возможно, QR-токену не хватает права iot:control. На компьютере создайте приложение Яндекс OAuth и запросите для него iot:view и iot:control. В платформе приложения укажите Redirect URI https://oauth.yandex.ru/verification_code. Затем получите токен для того же аккаунта по официальной инструкции и вставьте ниже. Проверка здесь только читает устройства; право управления проверяется при реальной команде.

Не отправляйте токен и полный адрес страницы OAuth в чат. По локальной сети эта панель работает без пароля и HTTPS, поэтому токен передаётся открытым текстом: используйте только доверенную сеть или защищённое соединение. На станции токен хранится зашифрованным. Это отдельное разрешение умного дома; вход для экрана и музыки сохраняется.
