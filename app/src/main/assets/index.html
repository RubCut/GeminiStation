Gemini API

Gemini Live отправляет аудио микрофона в Gemini API и может расходовать квоту. Для работы нужен доступ приложения к микрофону станции.

Экран станции — экспериментально

Свои анимации логотипа Gemini для матрицы 25×16. Подключение использует локальный протокол станции. Работа зависит от прошивки и пока не проверена на этом устройстве.

Файл содержит токен аккаунта Яндекса. Не отправляйте его никому. Импорт разрешён только через ADB: adb forward tcp:6529 tcp:6529, затем откройте http://127.0.0.1:6529. Токен сохраняется зашифрованным на станции и не показывается в журнале. Приложение отправляет его Яндексу для получения локального токена.
